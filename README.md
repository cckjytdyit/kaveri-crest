# Kaveri Crest

Premium coffee storefront built with Next.js.

## Local run

```bash
npm install
npm run dev
```

## Environment

Copy `.env.example` to `.env.local` and add your Stripe key.

```bash
cp .env.example .env.local
```

## Production deployment

- Push to GitHub
- Import into Vercel
- Add environment variables
- Set custom domain
- Use live Stripe keys
